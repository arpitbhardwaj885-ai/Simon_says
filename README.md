Simon Says Game

A simple Simon Says memory game built with HTML, CSS, and JavaScript.

The idea is pretty simple: Simon shows you a color sequence, and you have to remember and repeat it correctly. Every level adds another color, so the game gets harder as you go.

How to Play
Press any key to start.
Watch which button flashes.
Click the buttons in the same order.
Complete the sequence to move to the next level.
Click the wrong button and it's Game Over.

Example:

Level 1: Red
Level 2: Red → Purple
Level 3: Red → Purple → Green

How far can you go? Let's see. 🧠
